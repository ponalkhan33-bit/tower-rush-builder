# 🏗️ Tower Rush Builder

Tower Rush Builder is a casual mobile tower-building game designed
for simple, fun, and engaging gameplay.

## 🎮 Features

- Build and stack towers
- Simple gameplay
- Challenging tower levels
- Virtual in-game rewards
- Smooth and easy controls
- Free to play
- Ad-supported gameplay

## 📱 Platform

- Android
- Google Play Store
